# Legacy (ishlatilmaydi)

Bu yerda **oldingi bozor boti** qoldiqlari saqlanadi: `admin_handlers.py`, `callbacks.py`, `seller_flow.py`, `ai.py`.

**Joriy bot** ularni **yuklamaydi** (`app/bot.py` faqat ro‘yxatdan o‘tish handlerlarini ulaydi).

Agar qayta tiklash kerak bo‘lsa, import yo‘llarini va `app/keyboards.py` (qidiruv klaviaturalari) holatiga moslang — hozirgi asosiy loyihada ular yo‘q.

`app/utils.py` repoda **qolgan** — `legacy/callbacks.py` va boshqa skriptlar `from app.utils` ishlatishi mumkin.
